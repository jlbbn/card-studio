## Matrix-level P0/P1 conclusion

The strongest existing coverage is local durability, idempotency, state classification, safe retry limits, redaction and local refund/reversal rules. P0 gaps are host authorization/issuer behavior, contactless-specific protocol behavior, and execution of the L3 matrix against the real kernel rather than only `LabKernelAdapter`. P1 gaps are late reconciliation, cross-process original invariants, rich PSE/PPSE and fault coverage, and a stateful synthetic ICC. No row in this matrix is evidence of L3 readiness, EMV compliance, physical validation, or certification.
